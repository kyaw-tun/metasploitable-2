# References

This assessment was completed as part of the Red Team Essentials course by WYWM (Greenbeam).

## Course

- WYWM (Greenbeam) — Red Team Essentials
   - Course material and exercises used as the basis for this assessment.
   
## Lab Environment

- Kali Linux — Attacker/host machine used for reconnaissance, enumeration, exploitation, and post-exploitation activities.
- Metasploitable 2 — Intentionally vulnerable target machine used for the hands-on assessments.
- QEMU / virt-manager — Used to run the virtual machines.

## Tools

- Nmap — Network and service discovery.
- SearchSploit — Searching for known exploits related to discovered services and software versions.
- Exploit-DB — Vulnerability and exploit reference.
- Metasploit Framework — Exploitation and post-exploitation.
- MSFvenom — Payload generation.
- LinPEAS — Linux privilege-escalation enumeration.
- LinEnum — Linux enumeration and privilege-escalation checks.
- Python 3 — Used to host files through a simple HTTP server.
- cURL — Used to retrieve files from the HTTP server during the assessment.

## Online References

- GTFOBins — Reference for using Unix/Linux binaries in unintended ways, including privilege-escalation techniques.

## Notes

The tools and references listed above are those used or consulted during the current assessment. Additional resources may be added as new techniques or discoveries are explored.
